# RFL v0.3.0 Release Notes

> [!NOTE]
> ### Historical Development Milestone (Unpackaged)
> Versions prior to `v0.5.0` (`v0.1.0`–`v0.4.0`) represent historical internal development milestones. They were **not published on PyPI or binary package registries**. For Python and C++ research workflows, use **RFL `v0.5.0` or later**.

RFL version 0.3.0 introduced initial experimental `pybind11` Python bindings and hermetic Please (`pleasew`) build rules.

---

## 1. Highlights

* **Python Bindings Prototype:** Initial `pybind11` C++ extension module for interactive Python prototyping.
* **Hermetic Build Tooling:** Added Pleasings and `BUILD` target definitions alongside CMake.
* **Dirac Operator Python Class:** Exported `DiracOperator` instantiation and eigenvalue computation to Python.

---

## 2. Compatibility & Requirements

* **C++ Standard:** C++17 conforming compiler.
* **Linear Algebra:** Armadillo ≥ 11.4.0.
* **Stochastic Engine:** GNU Scientific Library (GSL) ≥ 2.6.
* **Python Compatibility:** Python ≥ 3.8, pybind11 ≥ 2.10.
