# RFL v0.1.0 Release Notes

> [!NOTE]
> ### Historical Development Milestone (Unpackaged)
> Versions prior to `v0.5.0` (`v0.1.0`–`v0.4.0`) represent historical internal development milestones. They were **not published on PyPI or binary package registries**. For Python and C++ research workflows, use **RFL `v0.5.0` or later**.

RFL version 0.1.0 represents the initial extraction of Mauro D'Arcangelo's thesis code into a reusable C++ library for Noncommutative Geometry simulations.

---

## 1. Highlights

* **Historical Codebase Extraction:** Structured historical thesis code into `Cliff` and `Geom24` classes.
* **Barrett-Glaser Potential:** Implemented quadratic and quartic Dirac trace action $S(D) = g_2 \text{Tr}(D^2) + g_4 \text{Tr}(D^4)$.
* **Metropolis Sampling:** Implemented matrix coordinate proposal and acceptance updates for random fuzzy geometries.

---

## 2. Compatibility & Requirements

* **C++ Standard:** C++11/14 compiler.
* **Linear Algebra:** Armadillo.
* **Stochastic Engine:** GNU Scientific Library (GSL).
