# RFL v0.4.0 Release Notes

> [!NOTE]
> ### Historical Development Milestone (Unpackaged)
> Versions prior to `v0.5.0` (`v0.1.0`–`v0.4.0`) represent historical internal development milestones. They were **not published on PyPI or binary package registries**. For Python and C++ research workflows, use **RFL `v0.5.0` or later**.

RFL version 0.4.0 modernised the continuous integration matrix across Linux and macOS Apple Silicon runners, added CodeQL static security analysis, and established C++17 compiler standards.

---

## 1. Highlights

* **Multi-Platform CI Matrix:** Configured automated GitHub Actions workflows for Ubuntu and macOS runners.
* **Apple Silicon Compatibility:** Resolved Homebrew library and include path resolution on `arm64` macOS environments.
* **Security & Code Analysis:** Integrated GitHub CodeQL scanning into CI pipeline.

---

## 2. Compatibility & Requirements

* **C++ Standard:** C++17 conforming compiler.
* **Linear Algebra:** Armadillo ≥ 11.4.0.
* **Stochastic Engine:** GNU Scientific Library (GSL) ≥ 2.6.
