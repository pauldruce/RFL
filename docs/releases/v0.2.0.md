# RFL v0.2.0 Release Notes

> [!NOTE]
> ### Historical Development Milestone (Unpackaged)
> Versions prior to `v0.5.0` (`v0.1.0`–`v0.4.0`) represent historical internal development milestones. They were **not published on PyPI or binary package registries**. For Python and C++ research workflows, use **RFL `v0.5.0` or later**.

RFL version 0.2.0 refactored the legacy simulation codebase into a modern modular structure with GoogleTest unit testing.

---

## 1. Highlights

* **Modular C++ Refactoring:** Introduced initial modular classes (`DiracOperator`, `Clifford`, `BarrettGlaserAction`, `Metropolis`).
* **GoogleTest Integration:** Converted historical test suites into structured `gtest` parameterised unit tests.
* **Modern CMake Architecture:** Established target-based CMake build configuration.

---

## 2. Compatibility & Requirements

* **C++ Standard:** C++17 conforming compiler.
* **Linear Algebra:** Armadillo.
* **Stochastic Engine:** GNU Scientific Library (GSL).
